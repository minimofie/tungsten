# Tungsten — round P0 fixes checklist (8 items)

Install the folder from the new `Tungsten_p0.zip` (replaces the earlier one;
P0a and P0b checklists still apply to it).

## A. Plugins tab
- **A1** Open Plugins: the tungsten card's orange outline sits fully below the PLUGINS heading, with a small gap; nothing overlaps.

## B. Window size (scale)
- **B1** `/scale 1.3`: the window and the explorer get bigger; text, icons, buttons and rows stay the same size.
- **B2** At 1.3 the console, explorer tree and path bar show more (more lines / rows / room).
- **B3** Right-click menus, dropdowns, tooltips and dialogs are the same size at 1.3 as at 1.
- **B4** `/scale 0.75`: the window gets smaller; contents keep their size. Note anything that no longer fits or is cut off.
- **B5** Plugins › tungsten › Window size stepper shows the percent and + / − change the window size.
- **B6** `/scale 9` warns and stops at the biggest size that fits your screen.
- **B7** `/scale 1` (or Reset all) puts the window back to its normal size.
